en local, afin de pouvoir naviguer dans l'export en ouvrant simplement
les fichiers .html dans un navigateur.

LIMITES IMPORTANTES — CE N'EST PAS UN CLONE FONCTIONNEL
---------------------------------------------------------
Wix ne propose aucune fonction officielle d'export du code source. Ceci
est donc une capture "best effort" du rendu public, avec les limites
suivantes :

1. Images, polices et feuilles de style restent chargées depuis les
   serveurs Wix (static.wixstatic.com, static.parastorage.com, etc.).
   Le rendu visuel est donc fidèle tant que ces ressources Wix restent
   accessibles, mais rien n'est réellement "hébergé ailleurs" — si le
   site Wix est supprimé, ces éléments cesseront de se charger.

2. Le formulaire de contact, les animations avancées, le chat/HELP,
   et toute autre fonctionnalité dynamique gérée par le moteur Wix
   (Thunderbolt) NE fonctionneront PAS de façon fiable une fois sorties
   de l'environnement Wix — elles dépendent de scripts liés au site ID
   et à l'infrastructure Wix.

3. Ce n'est pas une base pour une migration technique "clé en main"
   vers un autre hébergeur : pour un vrai site autonome (WordPress,
   HTML statique propre, etc.), il faudra reconstruire les pages avec
   le contenu récupéré ici comme référence (textes, structure, visuels).

RECOMMANDATION
---------------
Si l'objectif est de quitter Wix, la meilleure approche reste de
reconstruire le site sur la nouvelle plateforme cible en copiant le
contenu (textes, images téléchargées, structure des pages) depuis cet
export, plutôt que d'essayer d'utiliser ces fichiers HTML tels quels
comme site de production.
